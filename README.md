# Icebreaker Bot for Microsoft Teams

A simple Teams chat agent that conducts AI-powered icebreaker activities right inside your meeting chat — no audio infrastructure, no extra Azure services.

The bot joins the meeting chat, goes around each participant with a fun question, and uses a GenAI model to generate varied, contextual responses. You can fully customise its personality and instructions by editing a single text file.

---

## Quick Start (5 minutes)

### What you need

| Requirement | Cost | Notes |
|---|---|---|
| Microsoft 365 account with Teams | Existing corporate account | |
| Azure AD App Registration | Free | Register the bot identity |
| OpenAI API key **or** Azure OpenAI | Pay-per-use | Optional — works without it using scripted responses |
| [ngrok](https://ngrok.com/download) (local dev) **or** any HTTPS host | Free tier | Gives the bot a public URL |
| Node.js ≥ 18 | Free | |

---

### Step 1 — Register the bot in Azure

1. Go to [portal.azure.com](https://portal.azure.com) → **App Registrations** → **New registration**
2. Name it `Icebreaker Bot`, leave the defaults, click **Register**
3. Copy the **Application (client) ID** — this is your `MICROSOFT_APP_ID`
4. Go to **Certificates & Secrets** → **New client secret** → Copy the value — this is your `MICROSOFT_APP_PASSWORD`

---

### Step 2 — Install and configure

```bash
git clone https://github.com/pleite/icebreaker-audio-bot.git
cd icebreaker-audio-bot
npm install
cp .env.example .env
```

Edit `.env` and fill in the three required values:

```env
MICROSOFT_APP_ID=<paste App ID>
MICROSOFT_APP_PASSWORD=<paste client secret>
CALLBACK_BASE_URL=https://xxxx.ngrok-free.app   # fill in after Step 3
```

Optionally add an AI key for dynamic responses (highly recommended):

```env
OPENAI_API_KEY=sk-...
```

---

### Step 3 — Expose the bot publicly with ngrok

```bash
# In a separate terminal:
ngrok http 3978
```

Copy the `https://xxxx.ngrok-free.app` URL into `CALLBACK_BASE_URL` in your `.env`.

---

### Step 4 — Register the messaging endpoint in Azure

1. Azure Portal → **Azure Bot** (create a new Bot resource, or use the app you registered in Step 1)
2. Set **Messaging endpoint** to: `https://xxxx.ngrok-free.app/api/messages`
3. Under **Channels**, enable **Microsoft Teams**

---

### Step 5 — Build the Teams app manifest

```bash
npm run setup
```

This generates `manifest/manifest.zip` with your App ID, ready to upload to Teams.

---

### Step 6 — Upload to Teams and run

```bash
npm start
```

In Teams: **Apps** → **Manage your apps** → **Upload an app** → select `manifest/manifest.zip`.

Add the bot to any meeting chat — it starts the icebreaker automatically!

## How it works

```
You invite the bot to a Teams meeting
        ↓
Bot discovers the meeting roster (or adds participants dynamically as they reply)
        ↓
AI generates a welcome message and explains the activity
        ↓
Bot goes through each participant in turn:
  → AI generates a prompt for that person
  → Person types their response in the meeting chat
  → AI generates a contextual acknowledgement
        ↓
AI generates a closing wrap-up message
```

All spoken text is generated by the AI using the configurable instructions. If no AI key is configured, the bot falls back to built-in scripted text so it always works.

## Chat commands

| Command | What it does |
|---|---|
| `start` | Start (or restart) the icebreaker |
| `skip` | Skip the current participant's turn |
| `stop` | End the current session |
| `status` | Show progress and session info |
| `help` | Show all commands and available activities |

## Activities

The bot randomly selects one activity per session:

| Activity | Description |
|---|---|
| 🎭 **Two Truths and a Lie** | Each person shares two truths and one lie; others guess which is the lie |
| 🤔 **Would You Rather** | Each person answers a fun hypothetical question |
| 💡 **Fun Fact Round** | Each person shares one surprising fact about themselves |
| ⚡ **Speed Introductions** | 30-second intro: name, where you're from, one passion |

Force a specific activity by setting `DEFAULT_ACTIVITY` in your `.env`.

## Customise the bot's personality

The bot's tone and instructions are fully customisable. Create an `instructions.txt` file in the project root:

```bash
cp instructions.txt.example instructions.txt
# Edit instructions.txt to your liking, then restart the bot
```

Example custom personalities:

```
# Formal corporate facilitator
You are a professional corporate facilitator. Keep the icebreaker focused
and time-efficient. Remain neutral and respectful at all times.
```

```
# Fun pirate theme
Ye be a hearty pirate captain running an icebreaker for yer crew!
Speak like a pirate throughout but keep questions appropriate for work.
```

You can also set instructions via environment variable (useful for Docker):

```env
ICEBREAKER_INSTRUCTIONS=You are a very enthusiastic tech-themed icebreaker host.
```

Priority: `ICEBREAKER_INSTRUCTIONS` env var → `ICEBREAKER_INSTRUCTIONS_FILE` → `instructions.txt` → built-in default.

## Deploy to Azure (production)

### Option A — Azure Web App (simplest)

```bash
# Create an Azure Web App (B1 tier, ~$13/month, or free F1 for testing)
az webapp create --resource-group myRG --plan myPlan --name my-icebreaker-bot --runtime "NODE:20-lts"

# Set environment variables
az webapp config appsettings set --name my-icebreaker-bot --resource-group myRG \
  --settings MICROSOFT_APP_ID=... MICROSOFT_APP_PASSWORD=... \
             CALLBACK_BASE_URL=https://my-icebreaker-bot.azurewebsites.net \
             OPENAI_API_KEY=...

# Deploy
az webapp deployment source config-local-git ...
```

Update the **Messaging endpoint** in your Azure Bot to `https://my-icebreaker-bot.azurewebsites.net/api/messages`.

### Option B — Docker

```bash
# Build and run locally
docker-compose up --build

# Or push to any container registry and deploy to Azure Container Apps
docker build -t icebreaker-bot .
```

## Architecture

```
Teams Meeting Chat
      │  (Bot Framework webhook)
      ▼
  src/index.js          ← Express HTTP server
      │
  src/bot.js            ← IcebreakerBot (ActivityHandler)
      │                    - Roster discovery (TeamsInfo)
      │                    - Turn management
      │                    - Command handling
      ▼
  src/aiManager.js      ← Wraps Azure OpenAI / OpenAI
      │                    - Configurable instructions
      │                    - Conversation history context
      │                    - Scripted fallback
      ▼
  src/icebreakerActivity.js  ← Pure state machine (no cloud deps)
                               - IcebreakerSession
                               - Participant tracking
                               - Fallback scripts
```

## Teams app manifest

The manifest in `manifest/` describes the bot to Teams. Key things to update before publishing to your organisation's app catalogue:

- Replace `"id"` and `"botId"` with your actual `MICROSOFT_APP_ID`
- Update `"developer"` fields with your organisation's details
- Replace placeholder icons (`color.png`, `outline.png`) with your branded icons
- Run `npm run setup` after any changes — it re-generates `manifest.zip`

For the bot to read meeting rosters, add the following RSC permission to `manifest.json`:

```json
"webApplicationInfo": {
  "id": "<YOUR_APP_ID>",
  "resource": "https://graph.microsoft.com"
},
"authorization": {
  "permissions": {
    "resourceSpecific": [
      { "name": "ChatMember.Read", "type": "Delegated" }
    ]
  }
}
```
